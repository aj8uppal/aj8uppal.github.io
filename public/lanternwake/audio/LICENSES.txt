Original field recording: close stereo bow wave from an approximately eight-meter
sailing boat in calm water; recorded using two Neumann KM183 microphones and a
Tascam HD-P2. No original Saltline audio was used.

Changes for Lanternwake: excerpt from 00:10 to 01:00; gentle 65 Hz high-pass and
6.5 kHz low-pass filtering; +9.4 dB level adjustment; three-second equal-power
seam crossfade and rotation into a 47-second loop; encoded as stereo 44.1 kHz
128 kb/s MP3. Original source and reproducible processing script are retained
under art/incoming/audio. The runtime file is 753,325 bytes.
