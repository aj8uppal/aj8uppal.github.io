# Filefossil

> Drop any file into the browser and excavate the creature hiding in its bytes.

Filefossil is a dependency-free static web app that reads a file locally, measures its byte distribution, and turns those measurements into a deterministic, rotatable skeletal specimen. It shows the measurements and their morphological effects, lets you mutate bytes in memory, and can export the current specimen as a PNG plate.

## Run

Serve `~/personal` over HTTP on port 8900, then open:

```text
http://localhost:8900/filefossil/
```

For example:

```sh
cd ~/personal
python3 -m http.server 8900
```

Demo mode is the default and initially loads the synthetic `atlas.zip` specimen. `?demo=1` forces demo mode; `?demo=0` forces live mode with no specimen preloaded:

```text
http://localhost:8900/filefossil/?demo=1
http://localhost:8900/filefossil/?demo=0
```

## How it works

The browser reads up to the first 32 MiB in 512 KiB chunks. The analyzer builds a byte histogram, a histogram of adjacent-byte deltas, a 64-window entropy profile (or fewer windows for very small files), and a polynomial hash. Those values drive the drawing as follows:

| Visible trait | Byte measurement |
| --- | --- |
| Vertebral count | Overall entropy and entropy-profile roughness |
| Spine path and amplitude | Smoothed entropy profile and its min–max range |
| Dorsal spine height and profile | High-bit-byte ratio and per-window entropy |
| Rib count | Concentration of the histogram's eight most common byte values |
| Limb count and length | Equal-adjacent-byte ratio and adjacent-byte delta entropy |
| Tail length and taper | Printable-ASCII ratio |
| Skull form and horn count | Header-signature family |
| Shell pits | Null-byte ratio |
| Digits per limb | Number of distinct byte values |
| Dorsal plate count | Entropy-profile roughness |
| Body girth | Overall entropy and histogram concentration |
| Pigment | Header-signature family; entropy controls saturation |

Header sniffing recognizes a small fixed set of archive, document, image, executable, and media signatures; highly printable data without nulls is treated as plain text. A hash of the analyzed bytes deterministically supplies the invented binomial and catalogue numbers plus individual variation such as joint angles, curls, asymmetry, and ornament placement. Changing one byte updates the histograms and polynomial hash in memory, so the specimen can morph without rereading the file; Restore returns those in-memory edits to their original values.

The included samples are deterministic byte arrays generated by the app, not downloaded or representative files:

- `cipher.bin`: 256 KiB of uniform pseudo-random bytes, simulating ciphertext or compressed data.
- `journal.txt`: repetitive generated prose, simulating printable, compressible text.
- `ledger.dat`: fixed-width records with many null-padded fields and regular offsets.
- `plate.png`: a PNG signature and IHDR followed by pseudo-random “pixel” bytes; it is image-shaped, not a carefully constructed valid PNG.
- `atlas.zip`: repeated ZIP-like local headers containing alternating generated text and pseudo-random payloads, followed by an end marker; it is archive-shaped, not a complete valid ZIP.

## Known limitations

- Files larger than 32 MiB are represented only by their first 32 MiB.
- File-family labels are shallow signature checks, not format validation or parsing; extensions and MIME types are not used.
- The statistics are descriptive but coarse. Different files can produce similar measured anatomy, while a one-byte change can substantially reroll hash-derived details and the invented name.
- Mutations affect only the app's in-memory copy and cannot edit the source file.
- Empty files have nothing to render. The app also requires modern browser APIs including ES modules, Canvas, File/Blob, typed arrays, `ResizeObserver`, and pointer events.

Nothing is ever uploaded: after the static HTML, CSS, and JavaScript load, the app makes zero network requests at runtime. Filefossil makes no claim whatsoever about a file's content, meaning, or safety.
