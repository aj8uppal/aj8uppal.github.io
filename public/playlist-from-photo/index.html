Playlist From a Photo

One photo.
Twelve songs that feel like it.

Drop in any picture. You get a playlist poster you can post in about thirty seconds.

Demo build. This copy has no server, so the twelve songs below are a fixed set and the same every time. Your photo is still yours — the crop, the palette and the poster are all made from it. Run it with your own API key and Claude reads the picture instead.

Every song is checked against the Apple Music catalogue before it reaches your poster, so nothing on it is made up.
