    Demo rooms are drawn in code — no camera required. Photos and camera frames are read in the page and never uploaded.

    How it works. The scan samples frames into a small offscreen buffer, converts every pixel to OKLab, and clusters them with weighted k-means — colours are weighted by how persistently they appear across the whole sweep, not just by how much of the last frame they filled. The five surviving colours become a chord: hue picks the scale degree, lightness picks the register, chroma sets each voice’s brightness. Everything is quantised into one five-note mode, so it can be strange but never sour. The name is a deterministic function of the palette — same room, same name.
